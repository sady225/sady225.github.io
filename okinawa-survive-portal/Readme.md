# 沖縄サバイブポータル (Okinawa Survive Portal)

沖縄県内の社会資源・支援情報を集約し、困難を乗り越え「サバイブ」するための知恵をすべての人に届ける総合情報ポータルサイトです。

## 🚀 開発ログ (Current Status)

### 実装済みの機能
- **カテゴリ・地域別検索**: 助成金、食料、相談窓口等をキーワードや市町村でフィルタリング。
- **支援モデル**: 基本無料。サーバー維持・開発支援のための「開発アシスト権（サンクスメール付き）」販売。
- **決済・支援システム**: 投げ銭・開発支援（Buy Me a Coffee、Stripe）連携。
- **特定商取引法**: 外部ページ連携による「特定商取引法に基づく表記」への対応。
- **ポイントシステム**: ユーザー活動に応じたポイント管理機能（基盤）。
- **API連携基盤**: CORS対策としてのJSONP対応、および開発用モックデータの実装。
- **レスポンス・デザイン**: Bootstrap 5 を採用し、スマートフォン・PC両対応。

### 技術スタック
- **Frontend**: HTML5, CSS3 (Bootstrap 5, Bootstrap Icons)
- **Logic**: Vanilla JavaScript (Modular ES6 style)
- **Payment**: Stripe API
- **Backend API**: 外部GAS（Google Apps Script）またはNode.js APIを想定した連携

## 📈 今後の拡張案 (Future Roadmap)

1. **モバイルアプリ化**: Tauri または Capacitor 等を用いたデスクトップ/モバイルアプリ化。
2. **プッシュ通知機能**: 新着の助成金やイベント情報をリアルタイムで通知。
3. **インタラクティブマップ**: 施設や支援センターを地図上で直感的に探せる機能。
4. **LINE連携**: 公式LINEアカウントを通じた情報のパーソナライズ配信。
5. **AIコンシェルジュ**: ユーザーの状況（子供の年齢、地域）に合わせた支援情報を提案するAIチャット。
6. **コミュニティ機能**: 保護者同士が匿名で情報交換できる掲示板・SNS機能。

## ⚠️ リスク分析 (Risk Analysis)

### 技術的リスク
- **API依存性**: 外部API（GAS、Stripe等）の仕様変更やダウンによるサービス停止。
- **CORS/セキュリティ**: JSONPを使用している箇所のセキュリティ強化（可能な限り正式なCORSヘッダー対応への移行が望ましい）。
- **パフォーマンス**: 記事データ増大に伴う検索・リスト表示の低速化（キャッシュ機構の導入が必要）。

### 運用・ビジネスリスク
- **情報の鮮度維持**: 各自治体の助成金情報は変更が多いため、ソースの定期的な更新・確認が必要（現在は手動/一部自動を想定）。
- **個人情報の取扱い**: 有料会員の決済情報やプロフィール情報の厳重な管理（Stripeに委ねているが、サイト側の認証保護が必要）。
- **デジタル・ディバイド**: アプリ操作に不慣れな層へのアクセシビリティ担保。

## 🛠️ 開発者向け
- ステージング（開発モード）では `js/config.js` の `IS_DEV` を `true` に設定することで、APIサーバーなしでもモックデータで動作確認が可能です。
